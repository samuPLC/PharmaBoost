# Preferencias de este proyecto

- Mantener HTML, CSS y JavaScript; servidor Node.js y base MySQL. No introducir Python ni frameworks en la aplicación.
- Conservar la experiencia y los flujos del proyecto PharmaBoost anterior.
- Cada actualización entregada debe incluir un documento Word nuevo en docs con versión, cambios, pruebas realizadas y limitaciones pendientes. No sobrescribir informes anteriores.
- Mantener actualizada la lista de usuarios iniciales y las instrucciones de MySQL Workbench.
- No incluir credenciales de MySQL en documentos, repositorio ni archivos comprimidos.

- No mostrar paneles demo, accesos rápidos por rol, contraseñas ni simuladores de conexión en la interfaz. Documentar las credenciales iniciales de cada cuenta en el Word solicitado.
